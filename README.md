## Work

**DesignForge AI, founding engineer.** An AI co-pilot for RF design in Ansys HFSS. An engineer describes a design in plain language, and agents on the Claude Agent SDK build, simulate and debug it through PyAEDT. I own the agent stack: the harness (typed MCP tools, operating modes, a sandbox), the evaluation bench, the knowledge corpus and per-user memory. We demoed it live at IMS 2026.

## Public work

- **[AWARE](https://github.com/Kahl-d/Aware-Context-Aware-Multi-Label-Architecture)**: my M.S. thesis code. A transformer framework that reads each sentence in the context of its essay to identify Community Cultural Wealth themes in student writing, evaluated for severe class imbalance. The student essays stay private under the study's IRB protocol; the code, experiments and dashboards are here.
